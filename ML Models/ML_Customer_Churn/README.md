# 🟦 Customer Churn Prediction / Прогноз оттока клиентов

## 🇷🇺 Русский

**Описание проекта:**  
Проект демонстрирует полный workflow машинного обучения для прогнозирования оттока клиентов на основе числовых и категориальных признаков.  
Используются модели **Logistic Regression** и **CatBoostClassifier**.  
Метрика качества: **ROC-AUC**.

**Цели проекта:**

- 🔹 Изучение данных (EDA) и визуализация признаков  
- 🔹 Предобработка числовых и категориальных данных  
- 🔹 Обучение моделей и подбор оптимальных гиперпараметров  
- 🔹 Предсказание вероятностей оттока на тестовой выборке  
- 🔹 Сохранение результатов в `submission.csv`

**Структура проекта:**
ML_Customer_Churn/
│
├── notebooks/
│ └── churn_prediction.ipynb # Основной Jupyter Notebook
├── content/
│ ├── train.csv # Обучающие данные
│ ├── test.csv # Тестовые данные
│ └── submission.csv # Шаблон для результатов
├── requirements.txt # Список зависимостей Python
└── README.md # Документация проекта

**Как запустить проект:**

1. Клонировать репозиторий:  
```bash
git clone <URL_репозитория>

2. Установить зависимости:

pip install -r requirements.txt

3. Открыть notebooks/churn_prediction.ipynb в Jupyter Notebook или Google Colab и выполнить ячейки последовательно.

4. Результат прогнозов будет сохранён (и перезаписан) в content/submission.csv.
